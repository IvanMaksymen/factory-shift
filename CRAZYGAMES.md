# CrazyGames: перевірка станом на 18.10.2026

## Технічні рішення

Чисті JavaScript, HTML5 Canvas 2D, CSS та Web Audio. Нуль виробничих залежностей і сторонніх ігрових ресурсів. Графіка генерується кодом; шрифти системні. Автономне складання працює без мережевих запитів. Симуляція має фіксований крок 50 мс; рендеринг використовує requestAnimationFrame.

## Перевірені вимоги

Офіційні джерела:

- https://docs.crazygames.com/requirements/technical/
- https://docs.crazygames.com/requirements/gameplay/
- https://docs.crazygames.com/requirements/quality/
- https://docs.crazygames.com/sdk/intro/
- https://docs.crazygames.com/sdk/data/
- https://docs.crazygames.com/resources/basic-launch-metrics/

Основні технічні обмеження: до 250 МБ загалом і 1500 файлів; початкове завантаження до 50 МБ, для мобільної головної — до 20 МБ. Без SDK загальний розмір має вкладатися в початковий ліміт. Посилання на ресурси ігрового пакета мають бути відносними. Основні браузери — Chrome та Edge; мобільна версія потребує touch-керування. Для Full Launch за наявності прогресу потрібен Data module.

Інтерфейс має бути англійським і читабельним у стандартних iframe, включно з 821×462, 907×510 та 1216×684. Фізика не має залежати від частоти екрана. Власна кнопка fullscreen заборонена; її надає CrazyGames. У Full Launch до гри має вести не більше одного кліку. Неприйнятні чужі захищені матеріали та стороннє просування.

SDK v3 завантажується з `https://sdk.crazygames.com/crazygames-sdk-v3.js`. Перед викликами потрібно дочекатися `SDK.init()`. У середовищі `disabled` SDK не використовується.

Data module має синхронний інтерфейс getItem/setItem після ініціалізації. На CrazyGames він є єдиним сховищем гри; паралельне локальне збереження не використовується. При поданні треба правильно встановити перемикач Progress Save.

Basic Launch не вимагає SDK і не дозволяє рекламу. Офіційний тест триває 7–21 день: стандартно щонайменше 7 днів і 500 запусків, максимум 21 день при недосягненні кількості. Подальший Full Launch залежить від результатів і рішення платформи.

## Що реалізовано

- Автономний файл має приблизно 110 КБ — значно нижче лімітів.
- Англійський інтерфейс, вхід одним кліком, керування мишею, touch та клавіатурні скорочення.
- Адаптивні стилі, масштаб/пересування поля, safe-area відступи.
- Власні векторні ілюстрації та процедурні звуки; зовнішніх шрифтів, музики або зображень немає.
- Немає fullscreen-кнопки, сторонніх посилань у грі, реклами чи платежів.
- Окремий адаптер SDK: init, loadingStart/Stop, gameplayStart/Stop, Data, рідкісний happytime після кампанії.
- На CrazyGames помилка завантаження/ініціалізації SDK не запускає нову локальну гру поверх платформного збереження.
- Звук запускається жестом користувача; повторне resume AudioContext викликається після жесту, зокрема на touchend.

## Перед поданням

1. Провести живі тести у Chrome, Edge, Safari та на телефонах, зокрема малих iframe, background/foreground і переривання аудіо.
2. Перевірити зрозумілість навчання, баланс і бажання грати повторно з реальними тестувальниками.
3. Після дозволу власника перевірити платформне складання через CrazyGames Preview: SDK-події, Data для гостя/акаунта, сценарії помилок.
4. Підготувати обкладинки, опис та налаштування подання.
5. Лише після окремого дозволу власника подавати гру. Рекламну інтеграцію робити окремо для Full Launch.

Складання з SDK підготовлено для подальших перевірок, але це не підтвердження прийняття чи сертифікації CrazyGames. На платформі нічого не створювалося й не публікувалося.
